# 《失控游戏》

# 麻花（MAHUA / MH-08）角色造型圣经 V1.0

## CHARACTER DESIGN BIBLE

版本：V1.0\
角色编号：CHAR_MH08_MAHUA

------------------------------------------------------------------------

# 一、角色定位

## 一句话定义

> 一个2001年中国县城儿童乐园里没有离开的孩子。

麻花不是鬼童，不是NPC，也不是单纯的游戏引导角色。

她是晓晓被南建林记忆系统删除失败后留下的原始记忆残片。

她代表：

-   没有被听完的话；
-   没有被修补掉的真实；
-   被遗忘但仍然存在的童年。

------------------------------------------------------------------------

# 二、核心视觉命题

## 被遗忘，但仍然认真生活

麻花不是靠恐怖成立。

她的核心是：

一个孩子仍然在一个已经不存在的儿童乐园里，认真完成自己的日常。

------------------------------------------------------------------------

# 三、麻花与晓晓关系

         晓晓       麻花
  ------ ---------- --------------
  身份   真实孩子   记忆残留
  空间   家庭       星星岛
  颜色   明亮完整   褪色旧化
  材质   棉布       尼龙塑料
  状态   正在成长   停留在某一天

一句话：

> 晓晓是完整录像，麻花是被压缩后的残片。

------------------------------------------------------------------------

# 四、视觉锚点

## 1. 双麻花辫

固定：

左：暗红发绳\
右：旧蓝发绳

状态：

-   辫子略松；
-   发尾散开；
-   有碎发；
-   左右略不对称。

------------------------------------------------------------------------

## 2. 灰黄色儿童工作马甲

来源：

2000年前后儿童乐园工作人员服。

材质：

廉价尼龙。

细节：

-   拉链氧化；
-   边缘磨白；
-   缝线脱落；
-   星星岛贴章残留。

------------------------------------------------------------------------

## 3. 儿童身体比例

年龄：

8-10岁。

特点：

-   肩窄；
-   手臂细；
-   身体小。

禁止：

-   娃娃比例；
-   动漫比例；
-   恐怖鬼童比例。

------------------------------------------------------------------------

# 五、服装设计

## 马甲

核心资产。

定义：

一个孩子穿了一件大人的工作服。

------------------------------------------------------------------------

## 内搭

旧灰白T恤。

状态：

-   洗旧；
-   泛黄；
-   领口松。

------------------------------------------------------------------------

## 裤子

灰蓝儿童运动裤。

状态：

-   膝盖磨白；
-   裤脚旧。

------------------------------------------------------------------------

## 鞋

旧白布鞋。

细节：

-   鞋头发黄；
-   鞋底磨损。

------------------------------------------------------------------------

# 七、面部设计

核心：

第一眼普通，第二眼异常，第三眼心疼。

禁止：

-   白脸；
-   黑眼圈；
-   恐怖妆；
-   木偶笑。

恐怖来自：

她为什么还在这里。

# 十、删除状态设计

## 第一阶段：颜色消失

-   发绳褪色；
-   马甲变灰；
-   贴纸失去颜色。

## 第二阶段：录像损坏

-   声音拖尾；
-   边缘跳帧；
-   衣服纹理缺失。

## 第三阶段：记忆删除

-   辫梢消失；
-   手部丢帧；
-   身体局部透明。

原则：

不是鬼魂。

是被删除的数据。

------------------------------------------------------------------------

# 十一、动作设计

## 行走

熟悉空间，不像逃跑。

## 停止

听声音。

## 找路

不是思考，是身体记得。

## 回头

麻花最重要动作。

她经常确认：

有没有人跟上。

------------------------------------------------------------------------

# 十五、最终角色定义

> 麻花是一个穿着褪色儿童乐园工作马甲、扎着一红一蓝两根麻花辫的小女孩。她不是怪物，也不是鬼魂，她只是一个被留在2001年星星岛里的孩子，仍然认真守着那个已经不存在的游乐园。

------------------------------------------------------------------------

# 十六、主题关系

球童男孩：

坏掉的快乐。

麻花：

没有被听完的快乐。

晓晓：

真实存在过的快乐。

三者共同构成《失控游戏》的童年主题：

> 有些东西不是消失了，而是没有被完整记住。
